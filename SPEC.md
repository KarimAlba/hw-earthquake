# Спецификация

## Что делаем

Веб-приложение: землетрясения текущей календарной недели (пн–вс) по данным USGS.
Первая версия — список, фильтр и детали по клику; карта Leaflet отложена.

## Для кого и зачем

Для человека, которому нужно быстро посмотреть сейсмическую активность за выбранный день недели без установки приложений и без API-ключа.

## Сценарии

1. **Основной.** Открывает приложение → видит дни пн–вс, текущий день подсвечен и выбран → видит список землетрясений за этот день → может сменить день → отфильтровать список → кликает по записи и видит детали (место, магнитуда, время, глубина).
2. **Пустой день.** В выбранный день событий нет → видит понятное пустое состояние, не «сломанный» экран.
3. **Ошибка сети / API.** Загрузка не удалась → сообщение на русском и кнопка «Повторить».
4. **Загрузка.** Пока идёт запрос → видно состояние загрузки.

## Состояния

| Состояние | Что видит пользователь |
|---|---|
| Загрузка | Индикатор/текст загрузки списка |
| Есть данные | Список за выбранный день + активный фильтр; при выборе записи — блок деталей |
| Пусто | Текст вроде «За этот день землетрясений нет» |
| Ошибка | Сообщение об ошибке + «Повторить» |
| Дни недели | Полоса пн–вс; текущий день визуально выделен; выбранный день отличается от остальных |

## Чего точно не делаем

- Карту Leaflet в первой версии (закладываем место под неё позже).
- Авторизацию, личный кабинет, избранное.
- Бэкенд и прокси (клиент ходит в USGS напрямую).
- Push/уведомления, PWA, офлайн-кэш сверх текущего сеанса.
- Исторический выбор произвольных недель (только текущая пн–вс).
- Google Maps / платные картографические ключи.
- Админку и модерацию данных.

## Допущения

- Источник — **USGS** Earthquake API (не «USGC»): публичный GeoJSON, без ключа, CORS ок для учебного задания.
- «Неделя» — календарная **пн–вс** в локальной таймзоне пользователя; «текущий день» — сегодня в этой же зоне.
- Фильтр в MVP — по **минимальной магнитуде** (типичный сценарий для таких данных).
- Клик по «точке» в MVP = клик по **элементу списка** (карта отложена).
- Язык интерфейса — русский; исходные названия мест из USGS могут остаться как в API.

## Открытые вопросы

| Вопрос | Ответ |
|---|---|
| Роль / тема ДЗ | Frontend, карта землетрясений за неделю |
| Стек | React 19+, TypeScript, SCSS, Vite, FSD |
| Источник данных | USGS |
| Неделя | пн–вс, текущий день подсвечен и выбран по умолчанию |
| MVP UI | список рядом, фильтр, клик → детали; карту отложить |
| Карта (позже) | Leaflet |
| Ошибка сети | сообщение + «Повторить» |
| Язык UI | русский |
| Точные пороги фильтра магнитуды (0 / 2.5 / 4.5 / …) | пока не зафиксированы — предложить разумный набор при реализации |

## Критерии приёмки

- [ ] При открытии выбран и подсвечен текущий день недели (пн–вс).
- [ ] Список показывает события выбранного дня текущей недели по данным USGS.
- [ ] Смена дня обновляет список.
- [ ] Фильтр по магнитуде сужает список без перезагрузки страницы.
- [ ] Клик по записи открывает детали: место, магнитуда, время, глубина.
- [ ] Пустой день, загрузка и ошибка с «Повторить» отображаются корректно.
- [ ] UI на русском.
- [ ] Код на React 19+ / TypeScript / SCSS / Vite, структура по FSD.
- [ ] Карты в MVP нет (осознанно отложена).
