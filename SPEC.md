# Спецификация

## Что делаем

Веб-приложение: землетрясения текущей календарной недели (пн–вс) по данным USGS.
Список, фильтр, детали по клику и карта Leaflet (маркеры выбранного дня).

## Для кого и зачем

Для человека, которому нужно быстро посмотреть сейсмическую активность за выбранный день недели без установки приложений и без API-ключа.

## Сценарии

1. **Основной.** Открывает приложение → видит дни пн–вс, текущий день подсвечен и выбран → видит список и карту землетрясений за этот день → может сменить день → отфильтровать список/маркеры → кликает по записи или маркеру и видит детали (место, магнитуда, время, глубина); на маркере — короткий popup (место + M).
2. **Пустой день.** В выбранный день событий нет → видит понятное пустое состояние, не «сломанный» экран.
3. **Ошибка сети / API.** Загрузка не удалась → сообщение на русском и кнопка «Повторить».
4. **Загрузка.** Пока идёт запрос → видно состояние загрузки.

## Состояния

| Состояние | Что видит пользователь |
|---|---|
| Загрузка | Индикатор/текст загрузки списка |
| Есть данные | Список и карта за выбранный день + активный фильтр; при выборе записи/маркера — блок деталей и popup |
| Пусто | Текст «За этот день землетрясений нет» либо «Нет событий, подходящих под фильтр магнитуды» |
| Ошибка | Сообщение об ошибке + «Повторить» |
| Дни недели | Полоса пн–вс; текущий день визуально выделен; выбранный день отличается от остальных |

## Чего точно не делаем

- Авторизацию, личный кабинет, избранное.
- Бэкенд и прокси (клиент ходит в USGS напрямую).
- Push/уведомления, PWA, офлайн-кэш сверх текущего сеанса.
- Исторический выбор произвольных недель (только текущая пн–вс).
- Google Maps / платные картографические ключи.
- Админку и модерацию данных.

## Допущения

- Источник — **USGS** Earthquake API (не «USGC»): публичный GeoJSON, без ключа, CORS ок для учебного задания.
- «Неделя» — календарная **пн–вс** в локальной таймзоне пользователя; «текущий день» — сегодня в этой же зоне.
- Фильтр в MVP — по **минимальной магнитуде** (типичный сценарий для таких данных).
- Клик по «точке» = клик по **элементу списка** или **маркеру** на карте Leaflet (синхронизация выбора).
- Язык интерфейса — русский; исходные названия мест из USGS могут остаться как в API.

## Открытые вопросы

| Вопрос | Ответ |
|---|---|
| Роль / тема ДЗ | Frontend, карта землетрясений за неделю |
| Стек | React 19+, TypeScript, SCSS, Vite, FSD |
| Источник данных | USGS |
| Неделя | пн–вс, текущий день подсвечен и выбран по умолчанию |
| MVP UI | список рядом, фильтр, клик → детали |
| Карта | Leaflet: маркеры дня+фильтра, popup место+M, sync со списком; layout — список слева, карта+детали справа |
| Ошибка сети | сообщение + «Повторить» |
| Язык UI | русский |
| Точные пороги фильтра магнитуды (0 / 2.5 / 4.5 / …) | **все / ≥2.5 / ≥4.5 / ≥6.0** (зафиксировано в сессии 2) |

## Критерии приёмки

- [x] При открытии выбран и подсвечен текущий день недели (пн–вс).
- [x] Список показывает события выбранного дня текущей недели по данным USGS.
- [x] Смена дня обновляет список.
- [x] Фильтр по магнитуде сужает список без перезагрузки страницы.
- [x] Клик по записи открывает детали: место, магнитуда, время, глубина (дополнительно: координаты и ссылка на карточку USGS).
- [x] Пустой день, пустой результат фильтра, загрузка и ошибка с «Повторить» отображаются корректно.
- [x] UI на русском.
- [x] Код на React 19+ / TypeScript / SCSS / Vite, структура по FSD.
- [x] Карта Leaflet: маркеры видимых событий, popup (место + M), клик синхронизирован со списком/деталями.
