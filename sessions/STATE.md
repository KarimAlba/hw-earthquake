# Состояние проекта

**Обновлено:** 2026-08-19, сессия 2

## Готово

- Спека, Часть II `AGENTS.md`, README-визитка, `HOMEWORK.md`.
- Приложение в `earthquakes/`: Vite + React 19 + TS + SCSS + FSD.
- MVP: пн–вс с подсветкой сегодня, список USGS, фильтр магнитуды, детали, состояния загрузки/пусто/ошибка.

## В работе

- Ничего критичного; сессия 2 по MVP завершена.

## Не начато

- Карта Leaflet.
- Автотесты.
- Независимый ревью результата.

## Активные инструменты

- Vite 8, React 19, TypeScript, sass, oxlint (в `earthquakes/`).
- USGS Earthquake API.

## Известные проблемы

- `curl` к USGS на этой машине может падать на SSL revocation; `fetch` в Node/браузере работает.
- Пустой день зависит от реальных данных USGS за выбранную дату.
