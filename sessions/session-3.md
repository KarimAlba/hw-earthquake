### Замечания

| # | Severity | Где | Суть |
|---|---|---|---|
| 1 | важно | `EarthquakeList` + page | При активном фильтре пустой результат выглядит как «за день нет событий», хотя события есть |
| 2 | важно | `WeekEarthquakesPage` фильтр | При «Все» события с `magnitude: null` отсекаются (`-Infinity >= 0`) |
| 3 | важно | widgets/features/pages | Слайсы с единственной ссылкой — против правила FSD в `AGENTS.md` |
| 4 | мелочь | page | Смена фильтра не сбрасывает выбор; детали молча пустеют |
| 5 | мелочь | page | `today` фиксируется на mount — через полночь не обновится |
| 6 | мелочь | http / page | В ошибке может мелькнуть английский `HTTP NNN` |
| 7 | мелочь | `tsconfig.app.json` | Нет `"strict": true`, хотя в AGENTS заявлен strict |
| 8 | мелочь | `shared/lib/week` | Неиспользуемый `toIsoDate` |
| 9 | мелочь | `EarthquakeDetails` | Координаты и ссылка USGS сверх минимума SPEC (не баг) |
