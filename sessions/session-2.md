## Размышления

- План уже согласован: подпапка `earthquakes/`, без Leaflet, фильтр магнитуды «все / ≥2.5 / ≥4.5 / ≥6» как разумный набор из открытого вопроса спеки.
- `sass` нужен для SCSS в Vite — часть утверждённого стека.
- Данные тянем одним запросом на всю неделю (пн–вс), день и магнитуду фильтруем на клиенте — меньше нагрузки на USGS и проще смена дня.
- Alias `@/` + FSD: page собирает widgets/features, entity держит модель и API.
- oxlint ругался на `setState` в `useEffect` для сброса выбора — убрали эффект, подсветку и детали считаем из отфильтрованного списка.
- `curl` к USGS на Windows упал на SSL revocation offline; проверка через `node fetch` дала 200 — для агента этого достаточно, в браузере тот же fetch.
