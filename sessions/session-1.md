## Размышления

- Часть II `AGENTS.md` и `SPEC.md` были пустыми заготовками: без выбранной роли и продукта заполнять «в вакууме» нельзя — сначала зафиксировали Frontend и тему.
- В ответе написано «USGC», по смыслу и ДЗ это **USGS**; в спеке явно поправили название, чтобы агент не ходил в несуществующий API.
- «Карта» в названии задачи vs «карту можно отложить»: MVP без Leaflet, клик по точке = клик по элементу списка; Leaflet оставили на следующий этап, чтобы не раздувать первую сдаваемую вертикаль.
- Неделя как пн–вс (не «последние 7 суток») — другое поведение API: нужен расчёт границ текущей календарной недели и клиентская фильтрация/запрос по дням.
- Фильтр по магнитуде в ответах не детализирован — зафиксировали как допущение; пороги (0 / 2.5 / 4.5…) ещё открытый вопрос, предложить при реализации.
- Код и `npm create` пока не трогали: по правилам курса сначала описание, план и согласие.
- Старый `README.md` — это инструкция курса, а не визитка репо: сначала `ЗАДАНИЕ-ДЗ.md`, затем переименовали в `HOMEWORK.md` (правило: имена файлов только на английском); новый README — статус проекта + пометка про отпуск до 17.08.
