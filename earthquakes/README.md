# Earthquake Week (app)

Приложение в этой папке. Общая визитка репозитория — в корневом [`../README.md`](../README.md).

## Запуск

```bash
npm install
npm run dev
```

Откройте URL из вывода Vite (обычно `http://localhost:5173/`).

```bash
npm run build
npm run lint
```

## Стек

React 19 · TypeScript · SCSS · Vite · FSD
